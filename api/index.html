立場座標如何計算?

每筆 advocacy_position 之 stance_position 為 -100 ~ +100 之數值,依立場光譜軸(stance_axis_id)分布:

  • -100 ~ -80:強左(如「強落實派」全面廢除特教學校)
  • -79 ~ -30:偏左
  • -29 ~ +29:中性 / 混合 / 折衷
  • +30 ~ +79:偏右
  • +80 ~ +100:強右(如「強保留派」全面保留特教學校)

標籤(stance_label)為人類可讀之立場名稱(如 strong_inclusion / multi_track_preserve)。 座標數值由本平台基於該倡議者之公開立場文本判斷。異議申請:若您認為本平台對某立場之分類有誤,請透過 回饋表提出。
