PI-02：12 年來重大未兌現 CO 條目盤點

一、議題定位

本卡延伸 PI-01，盤點兩次審查（2017 / 2022）共 200+ 段 CO 中，2026 年仍未根本改善之關鍵條目。

二、四分類盤點框架

分類 定義
done 政策完成 + 成效可驗證
partial 政策啟動但成效有限 / 部分落實
pending 政策研議中 / 已承諾未啟動
abandoned 政府公開拒絕 / 修法卡關 / 預算未編

三、初步盤點（待 Wave 5+ 補實證）

預估 partial / pending 重點條目

  • §9 無障礙公共建築改善達成率（目標 vs 實際）
  • §12 監護宣告 → 支持式決策過渡進度
  • §19 機構式照顧人數 vs 社區支持人數比例
  • §24 融合教育師資配比 / 個別化教育計畫品質
  • §27 身障定額進用達成率 / 庇護工場過渡支持就業
  • §31 ICF 統計改革進度

預估 abandoned / 卡關項目

  • 個人助理員制度全面化（預算限制）
  • 跨部會 CRPD 主流化機制
  • DPO 實質決策參與
  • §11 緊急情況計畫納入身障者觀點
