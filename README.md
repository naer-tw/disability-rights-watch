# Disability Rights Watch Taiwan — 身心障礙者權利監督平台

由 [國教行動聯盟（AABE）](https://aabe.org.tw) 製作維護的 CRPD（身心障礙者權利公約）政策證據庫。

整合 CRPD 兩屆審查（2017 / 2022）國家報告、結論性意見、民間影子報告、政府後續回應、修法歷程與政策因果鏈追蹤。聚焦神經多樣性兒少校園處遇與醫療化爭議。

## 平台特色

- **16 PI 議題追蹤** — 4 軸框架（兌現追蹤 / NAP / 12 年指標 / 框架爭議旗艦），10/16 達因果鏈完整度 100/100
- **政策因果鏈系統**（本平台獨有）— 倡議 → 國際委員會 → 政府承諾 → 實施 → 結果評估，含「不公審原則」之責任歸屬說明
- **倡議者責任頁** — 9 倡議者累計立場、採納率、相關非預期後果
- **反向追溯查詢** — 從非預期後果回溯到原始倡議者
- **全平台搜尋** — 391 筆資料（206 CO / 63 倡議 / 27 LOI / 18 結果 / 16 PI / 15 修法 / 12 PDF / 11 承諾 / 8 法律）
- **影子報告 v0.1** — 5 audience 版本（專業 / 媒體 / 立法院 / 社群 / 身障當事人）skeleton
- **身障當事人入口** — 19px 大字 / 易讀模式 / 緊急離開 / 求助專線
