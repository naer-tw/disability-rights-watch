# CRPD 監督平台 使用手冊

> 給第一次來的人 — 用簡單的話告訴你「想做什麼,要看哪一頁」。
>
> 平台網址:https://naer-tw.github.io/disability-rights-watch/
>
> 如果你只有 30 秒,就看這份手冊的第一段「我第一次來,該看哪裡?」。

---

## 30 秒導讀:依「你是誰」找入口

| 你是 … | 先看這裡 |
|---|---|
| 一般人 / 第一次來 | 首頁 → 易讀版 → 16 議題地圖 |
| 身心障礙者本人 | 易讀版 → 身障者入口 → 你關心的議題 |
| 記者 | 關鍵發現 → 媒體懶人包 → 該議題 dossier |
| 立委 / 助理 | 立法委員版報告 → NAP → 該議題 dossier |
| NGO 起草影子報告 | 影子報告索引 → CRPD 50 條反向索引 → 立場彙整 |
| 研究者 | API / 開放資料 → 因果鏈總覽 → 全文搜尋 |
| 政府人員 | 官方文件入口 → NAP → 衛福部官網鏡像 |

## 一、入口頁(每個人都該認識的 4 頁)

### 1. 首頁(index.html)
**做什麼用:** 30 秒搞懂這個平台是什麼、看 6 種人怎麼用平台。

**什麼時候用:**
- 第一次來,想知道平台有什麼。
- 想分享給朋友看 — 直接傳首頁網址。
- 從其他地方來,要找入口。

**怎麼用:** 進首頁,先看「我是 ___」六格(身障者 / 家屬 / 記者 / 立委 / 研究者 / 政府)。挑一格,直接跳到對應頁。

---

### 2. 關於本平台(about.html)
**做什麼用:** 告訴你這個平台是誰做的、為什麼做。

**什麼時候用:**
- 想知道資料能不能信。
- 想引用平台,要寫「來源」。
- 學校老師問「這誰做的?」。

**怎麼用:** 看完知道:國教行動聯盟(AABE)做的,CC BY 4.0 授權,可以自由引用,要註明來源。

---

### 3. 方法論(methodology.html)
**做什麼用:** 解釋平台「怎麼挑議題、怎麼評分、怎麼處理對立面」。

**什麼時候用:**
- 看到一個結論覺得「這真的嗎?」 → 看方法論。
- 寫論文要附「資料來源說明」 → 引用方法論。
- 想學怎麼做這種平台 → 方法論是 SOP。

**重點概念:** 「不公審原則」 — 不偏袒任何一方,把對立立場都呈現,讓讀者自己判斷。

---

### 4. 意見回饋(feedback.html)
**做什麼用:** 你發現資料錯了 / 缺了 / 有要補的,在這裡提交。

**什麼時候用:**
- 你的團體有提過影子報告,但平台沒收。
- 你看到日期/名字打錯。
- 你想加一筆訴訟案例。
- 你想當倡議者讓平台收錄你的立場。

**怎麼用:** 填表單即可。我們會審後加入 — 不會偽造,寧缺勿濫。

## 二、16 議題追蹤(平台核心 — 每張議題卡)

### 5. 議題追蹤頁(issues/PI-XX-dossier.html)
**做什麼用:** 一張卡,看完一個議題從「誰倡議 → 國際委員回應 → 政府承諾 → 實施結果」整條因果鏈。

**什麼時候用:**
- 朋友問你「教育權現在怎樣?」 → 直接傳 PI-10 dossier 給他。
- 寫文章要找一個議題的歷史 → 看 dossier 的時間軸。
- 開會要佐證 → dossier 上就有「政府某年承諾 X,但結果是 Y」。

**頁面有什麼:**
- 11 個區段:時間軸 / 立場光譜 / 倡議 / 政府承諾 / 結果評估 / 訴訟 / 修法 / 法條 / 指標 / 引用 / 相關議題
- 「資料覆蓋透明度徽章」 — 直接看到哪個階段資料還缺
- 「↓ 下載 .txt」按鈕 — 拿走媒體懶人包
- 因果鏈完整度評分(0-100)

**16 個 PI 議題:**
- **軸 1 識別/反歧視:** PI-01, PI-02, PI-03, PI-04, PI-06
- **軸 2 去機構化/服務:** PI-05, PI-07, PI-08, PI-13
- **軸 3 融合教育/就業:** PI-10, PI-11, PI-15
- **軸 4 司法/政治參與:** PI-09, PI-12, PI-14, PI-16

---

### 6. 議題列表(issues/index.html)
**做什麼用:** 一頁看到全部 16 議題,找你要的。

**什麼時候用:**
- 不確定哪個議題編號是哪一個 → 先看列表。
- 想看哪個議題完整度高 → 列表有評分。

---

### 7. 媒體懶人包(issues/media-kit/PI-XX.txt)
**做什麼用:** 純文字版的議題重點 — 可以直接 copy 進新聞稿。

**什麼時候用:**
- 你是記者,30 分鐘內要寫一條稿 → 下載 .txt 直接用。
- 你要演講,要 30 秒講完一個議題 → 看「30 秒導讀」段。
- 你要做懶人包圖卡 → 抓「關鍵數字」段就好。

**包含內容:**
- 30 秒導讀
- 5 個關鍵數字
- 倡議立場光譜
- 主要倡議者語錄
- 政府承諾 vs 結果
- 引用方式(APA 格式)

---

### 8. 議題 OG 縮圖(issues/og/PI-XX.svg)
**做什麼用:** 你把議題追蹤頁分享到 LINE/Facebook/Twitter 時,自動長這張圖。

**什麼時候用:** 不用主動用 — 你分享連結時自動顯示。

## 三、深度分析模塊(8 個進階工具)

### 9. 因果鏈總覽(chain.html)
**做什麼用:** 一頁表格看完 16 議題 × 5 階段資料覆蓋。哪個議題哪個階段最薄弱,一目了然。

**什麼時候用:**
- 你是 NGO 主管,要決定明年聚焦哪些議題 → 看哪些階段缺資料。
- 你要寫研究計畫,要說「台灣 CRPD 哪個面向最弱」 → 直接用這頁。
- 你要做募款簡報,要證明「平台用心做」 → 這頁是最好的成果展示。

---

### 10. 立場彙整(positions.html)
**做什麼用:** 24 個倡議者 × 16 議題的立場矩陣 — 誰主張什麼、誰被採納。

**什麼時候用:**
- 你想知道「殘聯在 PI-10 教育權主張什麼?」 → 找殘聯卡 → 點 PI-10。
- 你要寫聯名連署,要找「在 PI-08 融合教育有立場的團體」 → 點 PI-08 行 → 看誰有立場。
- 你要研究「哪個團體最常被國際委員會採納?」 → 看採納率排序。

---

### 11. 關鍵發現(findings.html)
**做什麼用:** 從 16 議題萃取出「有故事性」的發現 — 特別是「非預期後果」。

**什麼時候用:**
- 寫倡議文章要找「有衝擊力」的證據 → 這頁四類發現直接挑。
- 想跟朋友解釋「為什麼這個平台講『不公審』很重要」 → 看「非預期後果」段。
- 寫年度報告要列「平台這一年發現了什麼」 → 直接 copy 結構。

**四類發現:**
- 非預期後果(倡議成功但結果沒全好)
- 未兌現承諾(政府逾期 / 部分達成)
- 已被採納的倡議(成功案例)
- 關鍵指標惡化(數據佐證)

---

### 12. CRPD 50 條反向索引(crpd-articles.html)
**做什麼用:** 從「公約條文」切入 — 每一條對應到哪些議題、CO 段落、修法。

**什麼時候用:**
- 起草影子報告時,要寫「§24 教育權」段 → 看 §24 對應哪些議題。
- 國際委員問「你們 §27 工作權做得如何?」→ 看 §27 反向索引。
- 法律系學生研究 → 從條文起手最方便。

**怎麼用:** 點類別篩(原則/義務/公民政治權/經社權/特定族群/施行監督),或搜尋條號(A24)、中文(教育)、英文(education)。

---

### 13. 官方文件入口(crpd-official.html)
**做什麼用:** 6 區段彙整所有官方原始文件連結。

**什麼時候用:**
- 你要找 CRPD 公約原文 → 一頁找到。
- 你要找台灣國家報告 / 結論性意見 → 一頁找到。
- 你要找 NAP 行動方案、施行法規 → 一頁找到。

**6 區段:**
1. 聯合國 CRPD 公約原文(英 / 中譯 / 易讀 / 手語)
2. 結論性意見(2017 + 2022 + 2027 籌備)
3. 台灣國家報告
4. 議題清單(LOI)
5. 施行法規
6. 衛福部官網鏡像

---

### 14. 影子報告 / 政府報告(external-reports.html)
**做什麼用:** 歷年所有提交報告的索引 — 22 份影子報告 + 3 份政府報告。

**什麼時候用:**
- 起草第三次審查影子報告(2027)→ 先看前兩次有什麼。
- 想找「殘聯 2017 影子報告寫了什麼」 → 點殘聯卡看連結。
- 寫論文要 cite 影子報告 → 一頁找全。

---

### 15. NHRC 儀表板(nhrc-dashboard.html)
**做什麼用:** 國家人權委員會(2020 成立的獨立人權機構)在 CRPD 上講過什麼、被採納多少。

**什麼時候用:**
- 寫文章要 cite 「官方獨立機構」立場 → NHRC 是首選。
- 比較「政府 vs NHRC vs 民間」三方差異 → 從這裡起。
- 想知道「NHRC 在哪些議題最積極」 → 看立場數量排序。

---

### 16. 倡議者責任(actors/)
**做什麼用:** 24 個倡議者各一頁,看每個團體在每議題的立場 + 採納紀錄。

**什麼時候用:**
- 想跟某個團體合作 → 先看他們在哪些議題有立場。
- 監督某倡議者「主張和結果有沒有對齊」 → 看採納率 + 結果。
- 找「跟我議題有關」的盟友 → 找該議題覆蓋的倡議者。

---

## 四、法規 / 報告 / 行動方案

### 17. 法規索引(laws/)
**做什麼用:** 8 部相關法律一頁一頁列出 — 內容、修法歷程、對應公約條文。

**什麼時候用:**
- 想知道「身權法」現在版本在哪 → 點該法看。
- 寫修法建議 → 看現行條文 + 過去修法理由。
- 法律系上課 / 法律扶助個案 → 直接連結引用。

**主要法規:** 身權法 / CRPD 施行法 / 特殊教育法 / 心理衛生法 等。

---

### 18. 6 角色版報告(reports/v0.1-*.html)
**做什麼用:** 把 16 議題重點翻譯成「給某種人看」的版本。

**6 個角色版:**
- `v0.1-pwd.html` — 身障者本人版
- `v0.1-media.html` — 媒體記者版
- `v0.1-legislative.html` — 立法委員版
- `v0.1-professional.html` — 專業人員版(社工/治療師)
- `v0.1-social.html` — 社運者版
- `v0.1-general.html` — 一般大眾版

**什麼時候用:** 把對應角色版傳給對的人。立委不需要看記者版,反過來也是。

---

### 19. NAP 政府行動方案(nap.html)
**做什麼用:** 政府跨部會 NAP 行動方案 vs CO 116 段落對照表。

**什麼時候用:**
- 質詢時要點名「政府承諾 X 項目進度多少」 → 從 NAP 起。
- 監督政府要找「哪些 CO 沒對應到 NAP」 → 對照表直接看。
- 政府人員自查「我們 NAP 是否覆蓋全部 CO」 → 同上。

## 五、官方文件鏡像

### 20. 衛福部 CRPD 官網鏡像(sfaa/)
**做什麼用:** 把衛福部 CRPD 官網的 90 篇公告 + 173 PDF 全部鏡像下來,變成可搜尋。

**什麼時候用:**
- 衛福部官網被改、找不到舊資料 → 來鏡像找。
- 政府文件全文搜尋 → 走平台搜尋(已索引)。
- 大量下載做研究 → 用 sfaa/ 起點。

**為什麼要鏡像:** 政府網站常常改,公告會消失。鏡像保證 12 年資料還在。

## 六、特殊版本(無障礙)

### 21. 易讀版(for-disabled/easy-read.html)
**做什麼用:** 用最簡單的字、最短的句子,告訴你這個平台在做什麼。

**什麼時候用:**
- 你是身心障礙者本人,網頁太難讀 → 看易讀版。
- 你要跟認知障礙朋友 / 心智障礙者解釋平台 → 給他易讀版。
- 你做衛教,要找 CRPD §21 易讀範本 → 這頁就是。

**設計重點:**
- 字級 22-36px(比一般網頁大很多)
- 一句話只說一件事
- 用簡單的字
- 緊急電話用大字 + 可一鍵撥打(1957 / 110 / 113)

---

### 22. 身障者入口(for-disabled/index.html)
**做什麼用:** 給身障者本人的議題分流入口。

**什麼時候用:**
- 自己是身障者,想找跟自己有關的議題。
- 家屬陪伴身障朋友看平台 → 從這個入口比較簡單。

## 七、分析工具(進階使用)

### 23. 全平台搜尋(search.html)
**做什麼用:** 一個搜尋框,找全平台 545 筆資料。

**什麼時候用:**
- 找某個關鍵字「校園霸凌」「易讀版」 → 直接搜。
- 找某個年份「2021」 → 看那年有什麼 CO / 修法 / 報告。
- 找某個團體名字 → 看他在哪些地方出現。

**有 13 種類型:** PI 議題、倡議者、CO 段落、立法、訴訟、衛福部公告、報告 等。

---

### 24. 議題地圖(map.html)
**做什麼用:** 16 議題視覺化地圖 — 看「誰跟誰相關」。

**什麼時候用:**
- 找「跟 PI-08 融合教育有關的其他議題」 → 看地圖連線。
- 做簡報要一張「全議題圖」 → 用這頁截圖。

---

### 25. 雙議題對照(compare.html)
**做什麼用:** 同時看兩個議題並排比較。

**什麼時候用:**
- 想知道「教育權 vs 工作權,哪個進度比較好」 → 並排比較。
- 寫論文要對照「2017 vs 2022 兩次審查 CO 變化」。

---

### 26. 未被聽見的立場(unheard.html)
**做什麼用:** 列出「有人提過、但被國際委員會忽略 / 拒絕」的立場 13 條。

**什麼時候用:**
- 想知道「平台真的不公審嗎?」 → 看這頁就知道也呈現對立面。
- 寫文章要凸顯「主流敘事沒提到的事」 → 從這頁找素材。
- 起草第三次影子報告,想重提舊訴求 → 這頁是清單。

**為什麼重要:** 平台不只報「成功故事」,也誠實標出「沒被聽見的聲音」 — 這是不公審原則的最強體現。

---

### 27. 議題 × 軸別矩陣(matrix.html)
**做什麼用:** 16 議題 × 4 軸別 + 多種維度的交叉矩陣(內部分析用)。

**什麼時候用:** 內部規劃 / 學術研究 / 平台策展。一般使用者不需要。

---

### 28. 因果鏈軌跡(trace/)
**做什麼用:** 從「結果」反向追溯「誰倡議造成」的工具。

**什麼時候用:**
- 政策後遺症 — 想知道「為什麼會變成這樣?是誰當年主張的?」 → 從結果反追。
- 寫批判文章要追責任 → 但要小心「不公審」原則。

---

### 29. 平台自我審計(self-audit.html)
**做什麼用:** 平台對自己的弱點誠實揭露。

**什麼時候用:**
- 你懷疑「這平台有沒有偏見」 → 看自我審計就知道。
- 學者引用要附「資料限制說明」 → 直接 cite 這頁。

---

### 30. 證據積分卡(pi-evidence-scorecard.html)
**做什麼用:** 每個議題的「證據力」評分卡。

**什麼時候用:**
- 想知道「PI-XX 的論點有多扎實」 → 看評分。
- 學術發表要標「證據等級」 → 用這頁評等。

## 八、開放資料 / API(技術人員 + 研究者)

### 31. API 12 表(api/)
**做什麼用:** 全平台資料以 JSON + CSV 開放下載,授權 CC BY 4.0。

**什麼時候用:**
- 研究者要批量分析 → 下載 CSV 進 Excel / R / Python。
- AI 訓練 → 下載 JSON 餵模型(允許,但請註明來源)。
- 開發者要做 mashup → 用 API。

**12 表包括:** PI 議題 / 倡議 / CO 段落 / 承諾 / 結果 / 訴訟 / 修法 / 法律 / 等。

---

### 32. 即時 KPI(api/kpi.json)
**做什麼用:** 平台所有數字「現在」是多少 — 動態從資料庫算。

**什麼時候用:**
- 你的網站要嵌「CRPD 平台目前 X 議題 Y 立場」即時數字 → 用這個 API。
- 寫月報要對「最新數字」 → 抓 API。

---

### 33. RSS 訂閱(feed.xml)
**做什麼用:** 訂閱平台,新的議題追蹤更新 / 衛福部公告自動推到你的 RSS reader。

**什麼時候用:**
- 你是記者,想第一時間知道更新 → 訂閱。
- 你是 NGO 工作者,要監控政府公告 → 訂閱。
- 你用 Feedly / NetNewsWire / Reeder → 加上這個 feed.xml。
